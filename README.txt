기억 후진 보조(MRA) 인터랙티브 콘텐츠

구성
- index.html: 실행 파일
- assets/hyundai_topview.png: 첨부 정탑뷰 차량 이미지 최적화본

실행
1. 폴더 구조를 유지한 상태로 index.html을 브라우저에서 실행합니다.
2. 웹 서버에 업로드할 때도 index.html과 assets 폴더를 함께 업로드합니다.
3. 모바일 QR 시연은 HTTPS 호스팅을 권장합니다.

조작
- 화면을 누른 채 경로를 그립니다.
- 손가락을 떼면 차량이 전진하며 경로를 기억합니다.
- 도착 후 '기억 후진 보조 활성화' 버튼을 누르면 동일 경로를 역순으로 복귀합니다.
